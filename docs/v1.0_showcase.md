# v1.0 local showcase

The v1.0 showcase is a development-only portfolio environment. It runs the
real LangGraph workflow, PostgreSQL domain repositories, Outbox and Inbox
workers, signed Provider callbacks, Bearer authentication, RBAC, and tenant
ownership checks. The model-facing adapters are deterministic so reviewers do
not need an OpenAI or LangSmith key.

![OpsPilot local showcase console](assets/showcase-console.png)

## Start

Prerequisite: Docker Desktop with Compose v2.

```powershell
docker compose --env-file .env.showcase -f compose.yaml -f compose.showcase.yaml up --build -d
```

Open `http://127.0.0.1:3000`. All ports are bound to loopback and all committed
identities, tokens, Provider credentials, and data are synthetic.

Stop the environment without deleting its local demonstration database:

```powershell
docker compose --env-file .env.showcase -f compose.yaml -f compose.showcase.yaml down
```

## Evidence paths

- **Automatic refund:** pauses the actual Graph for human confirmation before
  an idempotent refund write.
- **Manual review and complaints:** create PostgreSQL support cases and
  immutable events visible only through the scoped internal API.
- **Provider lifecycle:** runs Graph → transactional Outbox → local Provider →
  signed webhook → Inbox worker. The UI exposes counts and statuses, never
  callback payloads or credentials.
- **Retry and recovery:** the synthetic `ORD-10012` Provider request fails once
  with HTTP 500, follows the real persisted retry path, and then completes. The
  Supervisor timeline reads payload-free attempt evidence from PostgreSQL.
- **Supervisor assignment:** accepts the active `agent-7` demo directory user
  and returns the same non-enumerating 404 for an unavailable target.

The browser keeps the selected demo token in React memory only. It does not
store it in local storage, cookies, Graph state, PostgreSQL, or server logs.

## Release validation

- Python: Ruff, mypy, frozen dependency sync, package build, and the complete
  non-PostgreSQL test suite.
- Frontend: ESLint, Vitest, TypeScript/Vite production build, and npm audit.
- Browser: Playwright drives the local Compose stack through a real refund
  interrupt/resume, Provider lifecycle, complaint case, valid assignment, and
  non-enumerating invalid-assignment path.
- Runtime: the isolated PostgreSQL stack records Outbox `published` and Inbox
  `processed`; an unauthenticated LangGraph request returns `401`.

## Security boundary

`SHOWCASE_MODE=true` is accepted only with development mode and the demo
identity provider. Production startup rejects the showcase boundary. The local
Agent Server image is intentionally separate from the hardened production
image, uses the in-memory LangGraph development runtime, and has no LangSmith
key or control-plane dependency. Domain records remain in the disposable local
PostgreSQL service.

The observability and fault boundary is documented separately in
[v1.0 observability and fault demo](v1.0_observability.md). The consolidated
architecture, compatibility, evidence, and limitation map is in the
[v1.0 portfolio release](v1.0_release.md).
